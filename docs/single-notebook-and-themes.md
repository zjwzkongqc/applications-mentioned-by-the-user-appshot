# 单记录本与配色预览

`/fresh/` 日常只使用“教练，我想打网球”。“网球搭子”已归档：成员、训练、照片和其他原始资料继续保存在原有表中，没有删除、合并或改换记录归属。

归档通过 `deploy/fresh/settings.mjs` 与 `notebook.mjs` 的部署策略实现：

- 账号首页仅返回正在使用的记录本，老成员登录后直接进入。
- 页面不再显示新建记录本的表单，后台也拒绝新建记录本。
- 归档记录本的普通接口和旧邀请入口返回归档提示，禁止继续修改。
- 归档不撤销账号身份；本人仍可使用恢复码登录，个人心愿和训练等值仍包含已保存的历史训练。
- 不给任何账号自动增加新成员权限；原本未加入当前记录本的球友，仍需用群邀请加入。
- 原先主动分享的只读球员卡仍按原规则访问。恢复归档记录本需重新调整部署策略；数据无需重建。

前端通过独立 `notebook.js`、`notebook.css` 加载，本次调整不影响旧站根入口。

## 五种配色 Demo

配色预览位于 `/fresh/themes/`，同一套示例记录和组件可切换：

| 地址片段 | 配色 |
| --- | --- |
| `#forest` | 奶油白＋墨绿 |
| `#gold` | 炭黑＋香槟金 |
| `#clay` | 暖白＋红土橙 |
| `#navy` | 雾白＋海军蓝 |
| `#sage` | 米白＋鼠尾草绿 |

Demo 使用固定示例数据，不请求后台、不读取登录身份、不修改正式应用的配色或训练记录。

验证使用 `npm run test:notebook:browser`、`npm run test:wishes:browser` 和 API 测试。线上检查只读。旧的线上临时建群验收流程已经关闭，避免给现有记录本添加测试成员或记录。
